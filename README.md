# Перевод военных документов США с английского на русский

Системный промпт для перевода военных и доктринальных документов США с сохранением терминологии, структуры и авторских формулировок.

Основные документы проекта:
- DoD 3000.07, с обязательным уточнением типа документа и редакции;
- FM 3-05, Army Special Operations, издание 2025 года;
- связанные доктринальные материалы, предоставленные пользователем.

Особое внимание уделяется:
- специализированной военной лексике;
- различению похожих сокращений, включая JSOTF и SOJTF;
- структурам командования и отношениям подчинённости;
- точной передаче анализа конфликтов, включая войну в Украине, если такой анализ присутствует в оригинале;
- использованию DoD Dictionary of Military and Associated Terms, June 2025.

> Проект представляет собой системный промпт и инструкции по его применению. Он не содержит самостоятельной программы перевода, поискового сервиса или готовой RAG-системы. Для автоматического поиска по словарю необходимо отдельно подключить инструмент поиска по файлам или RAG.

## 1. Содержимое репозитория

Рекомендуемая структура:

```text
.
├── README.md
├── translation_system_prompt.md
├── dictionaries/
│   └── Dict-of-Military-Terms-25.pdf
├── glossary/
│   └── approved_terms.csv
├── examples/
│   └── translation_request.md
└── translations/
```

Назначение файлов и каталогов:

- `translation_system_prompt.md`: основной системный промпт.
- `dictionaries/`: словари, используемые для проверки терминов и сокращений.
- `glossary/`: утверждённые русские эквиваленты терминов.
- `examples/`: шаблоны запросов.
- `translations/`: результаты перевода.

Кроме README и основного промпта, перечисленные файлы и каталоги необходимо подготовить самостоятельно.

Не публикуйте документы, словари и переводы, если у вас нет права на их распространение. Материалы с ограниченным доступом не следует размещать в публичном репозитории.

## 2. Быстрый старт

1. Откройте файл `translation_system_prompt.md`.
2. Скопируйте его содержимое в поле системных инструкций вашей модели или приложения.
3. Подключите словарь `Dict-of-Military-Terms-25.pdf`:
   - через поиск по загруженным файлам;
   - либо через собственную RAG-систему.
4. При наличии добавьте утверждённый русскоязычный глоссарий и проверенные ранее выполненные переводы.
5. Передайте исходный текст по шаблону из следующего раздела.
6. Проверьте результат по контрольному списку.

Если системные инструкции недоступны, можно передать промпт первым сообщением в новой беседе. При этом возможности поиска по словарю всё равно должны быть подключены отдельно.

## 3. Шаблон запроса

Создайте запрос со следующей структурой:

```text
[METADATA]
Документ:
Тип документа:
Дата или редакция:
Глава:
Пункт:
Страница:
Начало документа или продолжение:
Правила оформления сокращений:

[CONTEXT]
Утверждённые русские эквиваленты:
...

Проверенные ранее выполненные переводы:
...

Найденные статьи DoD Dictionary:
...

[SOURCE TEXT]
Вставьте исходный английский текст.

[COMMAND]
Переведи исходный текст на русский язык в соответствии с системным
промптом.

Проверь специализированные термины и сокращения по подключённому
словарю и утверждённому глоссарию.

Сохрани структуру, нумерацию, ссылки, модальность, отрицания,
географические названия и роли участников.

Не добавляй отсутствующие в оригинале сведения.

Если поиск по словарю недоступен или значение критичного термина
не удалось подтвердить, сообщи об этом в примечании переводчика.
Не выдавай предположение за проверенный факт.
```

Указывайте фактические реквизиты исходного документа. Не определяйте тип документа, номер или редакцию только по имени PDF-файла.

## 4. Работа со словарём

### Назначение словаря

DoD Dictionary используется для проверки:
- английских терминов;
- определений;
- сокращений и их расшифровок;
- различий между близкими понятиями;
- ссылок на доктринальные источники, если они приведены в статье.

Англоязычное определение не является утверждённым русским переводом. Русские эквиваленты следует брать из отдельно согласованного глоссария либо обозначать как рабочие.

### Вариант А. Поиск по загруженному файлу

1. Загрузите словарь в приложение, в котором выполняется перевод.
2. Убедитесь, что модель может обращаться к инструменту поиска по этому файлу.
3. Укажите словарь как обязательный источник проверки терминологии.
4. Для контроля запросите найденную статью и указание её местоположения.

Простое упоминание имени файла в промпте не означает, что модель получила доступ к его содержимому.

### Вариант Б. Собственная RAG-система

Рекомендуемый порядок обработки:

1. Извлечь текст PDF.
2. Проверить качество извлечения, особенно сокращения и многоколоночные страницы.
3. Разделить материал на словарные статьи, сохраняя термин вместе с определением.
4. Отдельно обработать раздел сокращений.
5. Сохранить метаданные каждой статьи.
6. Настроить поиск по точному написанию и смысловой близости.
7. Перед переводом извлекать статьи для терминов и сокращений исходного фрагмента.
8. Передавать найденные статьи модели в блоке `[CONTEXT]`.

Для сокращений сначала проверяйте точное совпадение. Похожее написание не является основанием считать сокращения равнозначными.

Рекомендуемые поля записи:

```json
{
  "term_en": "",
  "abbreviation": "",
  "definition_en": "",
  "source_title": "DoD Dictionary of Military and Associated Terms",
  "source_edition": "June 2025",
  "printed_page": "",
  "pdf_page": "",
  "section": "",
  "referenced_publication": ""
}
```

Номер печатной страницы и номер страницы PDF храните отдельно.

Не заполняйте отсутствующие сведения догадками.

## 5. Русскоязычный глоссарий

Для согласованных русских эквивалентов можно использовать CSV-файл:

```csv
term_en,abbreviation,term_ru,status,scope,source,notes
```

Назначение полей:
- `term_en`: полное английское наименование.
- `abbreviation`: исходное сокращение.
- `term_ru`: согласованный русский эквивалент.
- `status`: например, `approved` или `draft`.
- `scope`: документ, редакция или контекст применения.
- `source`: основание для выбора перевода.
- `notes`: ограничения и пояснения.

Только записи со статусом `approved` считайте утверждёнными.

Не включайте непроверенный перевод в обязательный глоссарий только потому, что модель уже использовала его ранее.

## 6. Особое внимание: JSOTF и SOJTF

При обработке этих и других похожих сокращений:

1. Сохраните исходное написание.
2. Найдите каждое сокращение отдельно.
3. Проверьте полное английское наименование.
4. Сопоставьте определение с контекстом исходного документа.
5. Выберите русский эквивалент по утверждённому глоссарию.
6. Не приписывайте структуре уровень, полномочия или подчинённость, которые не подтверждены источником.

Если русские формулировки совпадают или близки, сохраняйте исходные сокращения, чтобы различие между понятиями не исчезло.

Не создавайте искусственно разные русские названия только ради различия букв. Любое терминологическое разграничение должно опираться на смысл и источники.

## 7. Перевод анализа конфликтов

Если исходный текст содержит анализ войны в Украине или других конфликтов:

- сохраняйте географию, даты и участников;
- точно передавайте, кто совершает действие и кому принадлежит оценка;
- сохраняйте степень уверенности автора;
- не превращайте предположение в установленный факт;
- различайте описание реального события, учебный сценарий и прогноз;
- не смягчайте и не усиливайте политические и военные формулировки;
- не добавляйте собственные объяснения или выводы.

Наличие такого анализа необходимо устанавливать по исходному тексту. Не следует добавлять украинский или иной контекст только потому, что он ожидается пользователем.

## 8. Перевод большого документа

Для последовательной работы:

1. Разделите документ по смысловым границам: разделам, подразделам или группам абзацев.
2. Передавайте номер текущего фрагмента и его положение в документе.
3. Сохраняйте утверждённый глоссарий между запросами.
4. Добавляйте релевантные проверенные переводы предыдущих фрагментов.
5. Ведите список уже раскрытых сокращений.
6. После объединения выполните итоговую терминологическую и структурную проверку.

Не считайте каждый новый фрагмент началом документа. Повторное раскрытие сокращений регулируйте отдельно.

Не предполагайте, что модель помнит предыдущие фрагменты, если они не переданы в текущий контекст или не сохранены средствами приложения.

## 9. Разрешение противоречий

Если источники расходятся:

1. Проверьте даты, редакции и область применения.
2. Установите, содержит ли переводимый документ собственное определение термина.
3. Не заменяйте специальное определение документа общим словарным определением автоматически.
4. Не используйте утверждённый русский эквивалент механически, если он явно искажает смысл данного контекста.
5. Зафиксируйте существенное расхождение в примечании переводчика.

Проверенный локальный глоссарий определяет согласованную русскую форму, но не должен скрывать смысловое противоречие.

## 10. Контроль качества

Перед принятием перевода проверьте:

- [ ] Переведены все предложения, подписи, сноски и элементы таблиц.
- [ ] Нет добавленных фактов, пояснений или выводов.
- [ ] Сохранены числа, даты, единицы измерения и диапазоны.
- [ ] Не потеряны отрицания, условия и исключения.
- [ ] Сохранена разница между обязанностью, рекомендацией, разрешением и возможностью.
- [ ] Правильно определены субъекты и объекты действий.
- [ ] Сокращения проверены по доступным источникам.
- [ ] JSOTF и SOJTF не смешаны.
- [ ] Терминология согласована с контекстом и редакцией документа.
- [ ] Сохранены заголовки, нумерация и внутренние ссылки.
- [ ] Реальные события не перепутаны с учебными сценариями.
- [ ] Оценки автора не выданы за пояснения переводчика.
- [ ] Неподтверждённые значения отмечены явно.
- [ ] Нет чрезмерного использования тире.

## 11. Формат результата

По умолчанию:
- готовый русский перевод;
- исходная структура документа;
- оригинальные сокращения и обозначения там, где они необходимы;
- краткие примечания только при существенной неоднозначности.

Формат примечания:

```text
[Прим. пер.: значение сокращения не удалось подтвердить
по доступным источникам; сохранено исходное обозначение.]
```

Для проверки терминологии можно отдельно запросить:

```text
После перевода добавь таблицу:
английский термин | русский эквивалент | источник | статус проверки.

Указывай только действительно использованные источники.
Не придумывай страницы, определения и результаты поиска.
```

## 12. Ограничения

- Промпт не гарантирует полного отсутствия ошибок.
- Автоматический поиск требует реально подключённого инструмента.
- Отсутствие статьи среди результатов поиска не доказывает её отсутствия во всём словаре.
- Ошибки распознавания PDF могут искажать термины, сокращения и структуру текста.
- Словарь определённой редакции может не отражать изменения более поздних документов.
- Критичные термины и отношения командования требуют ручной проверки.
- Автоматический перевод не является официальным переводом документа.
````
